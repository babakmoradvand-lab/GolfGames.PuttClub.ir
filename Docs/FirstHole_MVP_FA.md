# نمونهٔ نخست زمین گلف — وضعیت پیاده‌سازی

## وضعیت قبلی و پیش‌نمونهٔ جدید

نسخهٔ پیشینِ وب یک سوراخ پار ۳، توپ با فیزیک ساده، و گلف‌باز GLB شامل کلیپ‌های `swing` و `putt` داشت. آن نسخه پس از تصمیم بازطراحی، از صفحهٔ اصلی Pages برداشته شد؛ فایل‌هایش در تاریخ Git مخفی نشده‌اند.

صفحهٔ فعلی `WebPreview/` پیش‌نمونهٔ رابط boot-to-playable است: نمای مفهومی باشگاه، ناوبری محیط و تعامل زمینه‌ای با نقطهٔ شروع، بدون login یا صفحهٔ مهمان. تعامل فعلی فقط انتقال نمایشی رابط است و نباید با گیم‌پلی واقعی اشتباه گرفته شود.

## وضعیت آزمون

- HTML و نحو JavaScript پیش‌نمونه بررسی شده‌اند.
- هنوز Safari واقعی روی iPhone 15 Pro، حالت Add to Home Screen/PWA، لمس، resize، و عملکرد شبکهٔ موبایل آزموده نشده است.
- این صفحه خروجی وبِ مستقل برای بازبینی UX است؛ Unreal Engine 5.8 و گیم‌پلی اصلی در پروژهٔ جداگانه ساخته می‌شوند.
- بعد از هر push، URL ثابت Pages باید پس از موفقیت workflow با HTTP 200 بررسی شود.
