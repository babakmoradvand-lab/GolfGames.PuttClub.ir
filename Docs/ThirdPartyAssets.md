## Golfer character — research-approved, not yet imported/tested in Unreal

- Local file: `Content/Characters/Golfer.glb` (glTF 2.0 binary, 7,665,876 bytes).
- Retrieved from the standalone third-party asset file `assets/golfer/golfer.glb` in [mikehellyer/simple-golf](https://github.com/mikehellyer/simple-golf), branch `main`, on 2026-10-18. The repository's latest visible golfer commit at time of review was `abfd05b4adefdf159750a6496096f8c508e26220`.
- This is an asset-only reference. No game code, architecture, or project files from that repository are used.
- Repository documentation identifies the mesh as a MakeHuman character assembled from CC0 MakeHuman asset packs, with swing/putt motion derived from CMU Graphics Lab Motion Capture Database subject 64. Its README identifies the polo shirt, wool pants, shoes, hat, short hair, eye, and skin assets used by the build script.
- MakeHuman Community states core graphic assets are CC0 and lists these exact named sources/assets as CC0: [license overview](https://static.makehumancommunity.org/about/license.html), [namuhekam male polo shirt in Shirts 01](https://static.makehumancommunity.org/assets/assetpacks/shirts01.html), [toigo wool pants in Pants 01](https://static.makehumancommunity.org/assets/assetpacks/pants01.html), [jujube newsboy cap in Hats 01](https://static.makehumancommunity.org/assets/assetpacks/hats01.html), and the system-asset pack for `shoes01`, `short02` hair, `eyebrow001`, `eyelashes01`, `high-poly` eyes, and `middleage_caucasian_male` skin: [system assets](https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html).
- The [CMU database terms](https://mocap.cs.cmu.edu/) say the data is free for all uses and may be included in commercially sold products, but may not be resold directly, including in converted form. Keep the motion embedded only as part of the complete game/character, never distribute or sell the animation data as a standalone product. Preserve this acknowledgment in product credits: “The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.”
- The source repository's MIT license applies to its software; it is **not** being used as the license basis for this GLB. Asset permission is assessed from the stated CC0 MakeHuman sources and the CMU database terms above.
- The GLB passed a basic file-header validation (glTF 2.0 magic/version and declared file length). This is not a visual, animation, device, or Unreal import test. Do not claim it is UE-ready until imported and checked in Unreal Engine 5.8.
