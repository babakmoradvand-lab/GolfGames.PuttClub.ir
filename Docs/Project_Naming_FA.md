# نام‌گذاری بازی‌ها

## قانون قطعی نام

- **گلف ۱**: بازی قبلی/نسخهٔ وبِ موجود.
- **گلف ۲**: بازی جدید با Unreal Engine 5.8.
- تیترها و عنوان‌های مرتبط باید با نام دقیق نسخه شروع شوند: `گلف ۱ — ...` یا `گلف ۲ — ...`.
- کد و دارایی‌های گلف ۱ و گلف ۲ را با هم ادغام نکنیم. هر دو می‌توانند در یک مخزن و یک push هم‌زمان منتشر شوند، اما خروجی‌ها و مسیرهایشان باید مشخص بماند.

## نگاشت فعلی مخزن

- ریشهٔ پروژهٔ `PuttClubNext.uproject` و کد/مستندات Unreal: **گلف ۲**.
- `WebPreview/index.html` و `WebPreview/game.js`: **گلف ۱**، نسخهٔ وب و تغییرات گیم‌پلی آن.
- `WebPreview/golf2-preview.html`: پیش‌نمونهٔ مفهومی رابط آغازین **گلف ۲**؛ این فایل هنوز بازی وبِ قابل‌بازی یا نسخهٔ Unreal نیست.

## قاعدهٔ انتشار

تغییرات گلف ۱ و گلف ۲ در یک commit/push هم‌زمان فرستاده شوند. پس از هر push، GitHub Pages در URL ثابت بررسی شود. نتیجهٔ build Unreal جداگانه و فقط پس از اجرا در Unreal Engine روی مک تأیید می‌شود.
