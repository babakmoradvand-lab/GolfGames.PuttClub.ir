# PuttClub Next — گلف ۱ و گلف ۲

طبق قانون نام‌گذاری، **گلف ۱** بازی قبلی/وبی و **گلف ۲** پروژهٔ جدید Unreal Engine 5.8 است. مسیرها و وضعیت هر دو در `Docs/Project_Naming_FA.md` مشخص شده‌اند.

## جهت ساخت گلف ۲

Matrix Awakens مرجع روش‌های فنی و انتقال سینما به تجربهٔ قابل‌کنترل است؛ Black Myth: Wukong مرجع ترکیب‌بندی، هویت بصری محیط و کیفیت نور؛ و فقط الگوهای رفتاریِ قابل‌استنباط از منابع عمومی GTA VI الهام‌بخش NPCها هستند. کد، asset، UI یا محتوای اختصاصی این بازی‌ها کپی نمی‌شود. معماری در `Docs/AAA_Rebuild_UX_Architecture_FA.md` ثبت شده است.

## گلف ۱ — نسخهٔ وب

`WebPreview/index.html` و `WebPreview/game.js` نسخهٔ وب گلف ۱ است. لینک ثابت Pages برای آزمون آیفون پس از هر push به‌روز و بررسی می‌شود. خط راهنما در گلف ۱ از توپ تا جام/پرچم است و با تغییر فیس، قدرت یا تکنیک عوض نمی‌شود؛ فقط پس از جابه‌جایی توپ به lie جدید به‌روزرسانی می‌شود. فیس روی جهت پرتاب و هوک/اسلایس روی قوس پرواز اثر می‌گذارند.

## گلف ۲ — پروژهٔ Unreal

ریشهٔ `PuttClubNext.uproject` متعلق به گلف ۲ است. `WebPreview/golf2-preview.html` فقط پیش‌نمونهٔ مفهومی رابط آغازین آن است و نه گیم‌پلی کامل. پروژهٔ Unreal فعلی شِل C++ با تنظیم UE 5.8 است؛ Unreal Editor/UnrealBuildTool در محیط عامل موجود نیست، بنابراین build نهایی هنوز تأیید نشده است.

## دارایی‌ها

منبع و مجوز مدل گلف‌باز در `Docs/ThirdPartyAssets.md` ثبت شده است. فایل محلی موتور: `Content/Characters/Golfer.glb`.
